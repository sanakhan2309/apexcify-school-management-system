# School Management System 🏫

A comprehensive and premium Full-Stack School Management System built using the **MERN Stack**. This project was developed as part of the Full Stack Web Development Internship at **Apexcify Technologys**, successfully completing 3 major assigned tasks.

## 🚀 Project Overview
This system is designed to streamline school operations by providing separate, dedicated dashboards for four user roles:
* **Admin:** Manage students, teachers, classes, subjects, fee structure, and approve leave requests.
* **Teacher:** Mark daily attendance, upload course materials, and manage exam schedules/marks.
* **Student & Parent:** Track academic progress, view attendance reports, check timetables, and apply for leaves online.

---

## 🛠️ Tech Stack
* **Frontend:** React.js, Tailwind CSS (for premium UI/UX)
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Authentication:** JWT (JSON Web Tokens) & Bcrypt for secure multi-role login

---

## ✨ Features Implemented
- **Multi-Role Authentication:** Secure login for Admin, Teacher, Student, and Parent.
- **Attendance Management:** Automated daily attendance and leave application system.
- **Fee & Invoice Management:** Clear tracking of fee status and invoice generation.
- **Academic Controls:** Class, subject, and exam schedule management.
- **Course Material Upload:** Teachers can seamlessly share study material with students.
